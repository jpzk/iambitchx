──[ what it does ]──────────────────────────────────────────────────

  ▌ IRC vocabulary
    /join /part /names /who /whois /msg /query /me /topic /invite
    /kick /op /deop /mode /away /nick /set /window /encrypt /verify
    /trust /devices /recover

  ▌ Matrix, properly
    end-to-end encryption, SAS emoji verification, device keys,
    recovery. login by OAuth device link or password; tokens
    refresh themselves before they expire.

  ▌ terminal native
    a BitchX-style status window, split windows, IRC-style
    timestamps, status bar and prompt. no mouse required.


──[ install ]───────────────────────────────────────────────────────

  every release ships for x86_64 linux (static musl), aarch64 linux,
  x86_64 macOS and x86_64 windows. current: v0.1.0 -- check the
  releases page for newer tags and swap the version below.

  releases: https://github.com/jpzk/iambitchx/releases

  R=https://github.com/jpzk/iambitchx/releases/download/v0.1.0

  ▌ deb  (debian, ubuntu; amd64 or arm64)
    curl -LO $R/iambitchx_0.1.0-1_amd64.deb
    sudo apt install ./iambitchx_0.1.0-1_amd64.deb

  ▌ rpm  (fedora, rhel, opensuse; x86_64 or aarch64)
    curl -LO $R/iambitchx-0.1.0-1.x86_64.rpm
    sudo dnf install ./iambitchx-0.1.0-1.x86_64.rpm

  ▌ tarball  (binary + man pages + desktop files)
    curl -LO $R/iambitchx-0.1.0-aarch64-unknown-linux-gnu.tar.gz
    tar xzf iambitchx-0.1.0-aarch64-unknown-linux-gnu.tar.gz

  ▌ musl  (static x86_64 linux, runs on any distro)
    curl -LO $R/iambitchx-0.1.0-x86_64-unknown-linux-musl
    chmod +x iambitchx-0.1.0-x86_64-unknown-linux-musl
    ./iambitchx-0.1.0-x86_64-unknown-linux-musl
    (also as iambitchx-0.1.0-x86_64-unknown-linux-musl.tar.gz)

  ▌ mac  (x86_64; runs under rosetta on apple silicon)
    curl -LO $R/iambitchx-0.1.0-x86_64-apple-darwin
    chmod +x iambitchx-0.1.0-x86_64-apple-darwin
    xattr -d com.apple.quarantine \
      iambitchx-0.1.0-x86_64-apple-darwin
    (also as iambitchx-0.1.0-x86_64-apple-darwin.tar.gz)

  ▌ windows  (x86_64)
    download iambitchx-0.1.0-x86_64-pc-windows-msvc.exe
    (or the .tar.gz) from the releases page and run it in
    windows terminal.

  ▌ from source
    cargo build --release
    ./target/release/iambitchx            # default profile
    ./target/release/iambitchx -P NAME    # another profile

  first start logs you in (OAuth device link or password).
  type /help for the command list.


──[ verify ]────────────────────────────────────────────────────────

  ▌ checksums -- download SHA256SUMS next to the files:
    curl -LO $R/SHA256SUMS
    sha256sum -c --ignore-missing SHA256SUMS
    (macOS: shasum -a 256 -c --ignore-missing SHA256SUMS)

  ▌ provenance -- proves the file was built by this repo's release
    workflow (SLSA build provenance, signed via Sigstore; needs the
    GitHub CLI, gh 2.49+):
    gh attestation verify iambitchx-0.1.0-x86_64-unknown-linux-musl \
      --repo jpzk/iambitchx

  ▌ stricter -- pin the workflow and the tag ref:
    gh attestation verify iambitchx-0.1.0-x86_64-unknown-linux-musl \
      --repo jpzk/iambitchx \
      --signer-workflow jpzk/iambitchx/.github/workflows/release.yml \
      --source-ref refs/tags/v0.1.0

  ▌ SBOM attestation (CycloneDX, x86_64 linux binary and tgz):
    gh attestation verify iambitchx-0.1.0-x86_64-unknown-linux-musl \
      --repo jpzk/iambitchx \
      --predicate-type https://cyclonedx.org/bom

  every release file has a build provenance attestation; without
  gh, the raw bundles are at
  https://api.github.com/repos/jpzk/iambitchx/attestations/
  sha256:DIGEST
