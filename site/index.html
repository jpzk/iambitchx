  channels, not rooms. IRC vocabulary, Matrix underneath,
  end-to-end encrypted.

──[ what it does ]──────────────────────────────────────────────────────

  ▌ IRC vocabulary
    /join /part /names /who /whois /msg /query /me /topic
    /invite /kick /op /deop /mode /away /nick /set /window
    /encrypt /verify /trust /devices /recover

  ▌ Matrix, properly
    end-to-end encryption, SAS emoji verification, device keys,
    recovery. login by OAuth device link or password; tokens
    refresh themselves before they expire.

  ▌ terminal native
    BitchX-style status window, split windows, IRC-style
    timestamps, status bar and prompt. no mouse required.

──[ install ]───────────────────────────────────────────────────────────

  every release ships, per target, a bare binary, a .tar.gz
  (binary + man pages + desktop files), and on linux .deb/.rpm.
  grab them from https://github.com/jpzk/iambitchx/releases

    V=0.1.0
    R=https://github.com/jpzk/iambitchx/releases/download/v$V

  ▌ debian / ubuntu (.deb, amd64 or arm64)
    curl -LO $R/iambitchx_${V}-1_amd64.deb
    sudo apt install ./iambitchx_${V}-1_amd64.deb

  ▌ fedora / rhel / suse (.rpm, x86_64 or aarch64)
    curl -LO $R/iambitchx-${V}-1.x86_64.rpm
    sudo dnf install ./iambitchx-${V}-1.x86_64.rpm

  ▌ any linux, static musl binary (x86_64)
    T=x86_64-unknown-linux-musl
    curl -LO $R/iambitchx-$V-$T.tar.gz
    tar xzf iambitchx-$V-$T.tar.gz
    ./iambitchx-$V-$T/iambitchx

  ▌ tarball, other targets
    aarch64-unknown-linux-gnu      linux arm64 (glibc)
    x86_64-apple-darwin            macOS intel
    aarch64-apple-darwin           macOS apple silicon
    x86_64-pc-windows-msvc         windows (.tar.gz or bare .exe)

  ▌ macOS
    T=x86_64-apple-darwin   # or aarch64-apple-darwin
    curl -LO $R/iambitchx-$V-$T.tar.gz
    tar xzf iambitchx-$V-$T.tar.gz

  ▌ windows (powershell)
    curl.exe -LO $R/iambitchx-$V-x86_64-pc-windows-msvc.exe
    .\iambitchx-$V-x86_64-pc-windows-msvc.exe

  ▌ from source
    cargo build --release
    ./target/release/iambitchx            # default profile
    ./target/release/iambitchx -P <name>  # another profile

  first start logs you in (OAuth device link or password).

──[ verify ]────────────────────────────────────────────────────────────

  don't trust, verify. every release file is listed in SHA256SUMS
  and carries SLSA build provenance, signed via Sigstore with the
  release workflow's OIDC identity.

  ▌ checksums (SHA256SUMS next to the downloads)
    curl -LO $R/SHA256SUMS
    sha256sum -c --ignore-missing SHA256SUMS
    # macOS: shasum -a 256 -c --ignore-missing SHA256SUMS

  ▌ provenance (GitHub CLI, gh 2.49+)
    gh attestation verify iambitchx-$V-$T.tar.gz \
      --repo jpzk/iambitchx

  ▌ stricter: pin the workflow and the tag
    gh attestation verify iambitchx-$V-$T.tar.gz \
      --repo jpzk/iambitchx \
      --signer-workflow \
        jpzk/iambitchx/.github/workflows/release.yml \
      --source-ref refs/tags/v$V

  ▌ SBOM attestation (CycloneDX, x86_64 linux binary + tgz)
    gh attestation verify iambitchx-$V-x86_64-unknown-linux-musl \
      --repo jpzk/iambitchx \
      --predicate-type https://cyclonedx.org/bom

  full notes: docs/release.md

──[ credits ]───────────────────────────────────────────────────────────

  ▌ the splash art
    the in-client startup logo is the original BitchX 1.3 art
    (art.c, do_ansi_logo()) in two variants: the 3D block logo,
    signed PhonyEye and Awe/Cia, and the "acidjazz" ASCII logo
    above. shipped decoded from CP437 to Unicode -- the original
    emits raw CP437 bytes, so a UTF-8 terminal always showed
    mojibake. redistributed under the BSD 3-Clause licence; the
    notice ships with the binaries (COPYRIGHT-BITCHX).

  ▌ the base code
    iamBitchX is a fork of iamb by Ulyssa (iamb.chat),
    Apache License 2.0. iamb's Matrix engine, sync loop, E2EE stack
    and store make this client possible; the frontend is new.
    support the project.

  ▌ everything else
    matrix-rust-sdk -- Apache-2.0 -- the Matrix SDK underneath.

    BitchX is by panasync (Colten Edwards) and contributors, created
    in 1995. iamBitchX shares no code with it -- only the look and
    the attitude.
