──[ what it does ]──────────────────────────────────────────────────

  ▌ IRC vocabulary
    /join /part /names /who /whois /msg /query /me /topic /invite
    /kick /op /deop /mode /away /nick /set /window /encrypt /verify
    /trust /devices /recover /create /alias /publish /ban /unban
    /kickban /power /ignore /unignore

  ▌ Matrix, properly
    end-to-end encryption, SAS emoji verification, device keys,
    recovery. login by OAuth device link or password; tokens
    refresh themselves before they expire.

  ▌ terminal native
    a BitchX-style status window, split windows, IRC-style
    timestamps, status bar and prompt. no mouse required.


──[ features ]──────────────────────────────────────────────────────

  ▌ Matrix
  * end-to-end encryption (Olm/Megolm via matrix-rust-sdk);
    /encrypt turns it on for a channel
  * SAS emoji verification: /verify start, accept, yes/no, cancel;
    incoming requests are offered, never auto-accepted
  * cross-signing and key backup enabled at login; /trust shows
    the status, /recover KEY imports secrets from secure backup
  * /devices [USER] lists devices and their keys
  * rooms as #channels, DMs as /msg and /query windows
  * /list searches the public room directory; spaces are tagged
    [space] in /list, /channels and their window
  * /join by alias or room id, /part, /topic, /invite, /kick
  * /op and /deop set power levels; /names, /who, /whois
  * /create #x [-public] [-noencrypt]: new channel on your own
    server, invite-only and encrypted by default; /join of a
    missing #x on your server offers to create it [y/n]
  * /alias add|del, /publish on|off (room directory)
  * /ban, /unban, /kickban; /power NICK 0..100 (not above yours)
  * /ignore NICK|@user:server, /unignore: the Matrix account
    ignore list; bare /ignore lists it, ignored senders are hidden
  * /mode maps IRC modes to room state: +i invite-only,
    +m moderated, +t topic lock, +o op, +b ban; bare /mode and
    the status bar show e.g. +it
  * read-only channels say which power level you need
  * presence: away/online sent and shown, /whois shows away
  * /nick sets your display name
  * history backfill when a channel window opens
  * not (yet): threads, reactions, edits, read receipts,
    typing notifications, media upload/download

  ▌ login
  * password (prompted, or password_file in the config)
  * SSO (single sign-on, opens the browser)
  * OAuth 2.0 / next-gen auth (MSC3861): browser login with a
    local loopback redirect
  * device link: OAuth 2.0 device authorization grant (RFC 8628)
    -- the terminal shows a URL and a code, approve the login in
    any browser. works over ssh and on headless boxes
  * tokens refresh before they expire; two processes on one
    profile share session.json behind a lock

  ▌ IRC / BitchX
  * /slap NICK -- the BitchX "Brown Cow" slap, sent as /me
  * /mircslap NICK -- the classic large trout, sent as /me
  * /away [msg] and /back; AWAY_NICK swaps your nick (%n^afk)
  * AUTO_AWAY: auto-afk after AUTO_AWAY_TIME secs idle (600),
    with AUTO_AWAY_MSG
  * /me (/action), /msg, /query, /channels, /window next|prev,
    /clear, /close, /quit, /version, /help
  * /set vars: TIMESTAMP, TIMESTAMP_STRING, AUTO_REPLY highlight
    words, BEEP on highlight
  * /lastlog [-i] TEXT searches the window, hits shown with
    their timestamps; /lastlog -clear drops them
  * /set LOG ON: irssi-style logs, LOG_DIR/server/#chan.log,
    DMs too; plain text, files 0600, debug output never logged
  * /theme with live preview: 62 iamb themes plus 'terminal'
  * alt-0..9 switches windows, tab completes nicks
  * /ctcp parses but says "Not supported on Matrix"

──[ install ]───────────────────────────────────────────────────────

  every release ships for x86_64 linux (static musl), aarch64 linux,
  x86_64 macOS and x86_64 windows. current: v0.1.0 -- check the
  releases page for newer tags and swap the version below.

  releases: https://github.com/jpzk/iambitchx/releases

  R=https://github.com/jpzk/iambitchx/releases/download/v0.1.0

  ▌ deb  (debian, ubuntu; amd64 or arm64)
    curl -LO $R/iambitchx_0.1.0-1_amd64.deb
    sudo apt install ./iambitchx_0.1.0-1_amd64.deb

  ▌ rpm  (fedora, rhel, opensuse; x86_64 or aarch64)
    curl -LO $R/iambitchx-0.1.0-1.x86_64.rpm
    sudo dnf install ./iambitchx-0.1.0-1.x86_64.rpm

  ▌ tarball  (binary + man pages + desktop files)
    curl -LO $R/iambitchx-0.1.0-aarch64-unknown-linux-gnu.tar.gz
    tar xzf iambitchx-0.1.0-aarch64-unknown-linux-gnu.tar.gz

  ▌ musl  (static x86_64 linux, runs on any distro)
    curl -LO $R/iambitchx-0.1.0-x86_64-unknown-linux-musl
    chmod +x iambitchx-0.1.0-x86_64-unknown-linux-musl
    ./iambitchx-0.1.0-x86_64-unknown-linux-musl
    (also as iambitchx-0.1.0-x86_64-unknown-linux-musl.tar.gz)

  ▌ mac  (x86_64; runs under rosetta on apple silicon)
    curl -LO $R/iambitchx-0.1.0-x86_64-apple-darwin
    chmod +x iambitchx-0.1.0-x86_64-apple-darwin
    xattr -d com.apple.quarantine \
      iambitchx-0.1.0-x86_64-apple-darwin
    (also as iambitchx-0.1.0-x86_64-apple-darwin.tar.gz)

  ▌ windows  (x86_64)
    download iambitchx-0.1.0-x86_64-pc-windows-msvc.exe
    (or the .tar.gz) from the releases page and run it in
    windows terminal.

  ▌ from source
    cargo build --release
    ./target/release/iambitchx            # default profile
    ./target/release/iambitchx -P NAME    # another profile

  first start logs you in (OAuth device link or password).
  type /help for the command list.


──[ verify ]────────────────────────────────────────────────────────

  ▌ checksums -- download SHA256SUMS next to the files:
    curl -LO $R/SHA256SUMS
    sha256sum -c --ignore-missing SHA256SUMS
    (macOS: shasum -a 256 -c --ignore-missing SHA256SUMS)

  ▌ provenance -- proves the file was built by this repo's release
    workflow (SLSA build provenance, signed via Sigstore; needs the
    GitHub CLI, gh 2.49+):
    gh attestation verify iambitchx-0.1.0-x86_64-unknown-linux-musl \
      --repo jpzk/iambitchx

  ▌ stricter -- pin the workflow and the tag ref:
    gh attestation verify iambitchx-0.1.0-x86_64-unknown-linux-musl \
      --repo jpzk/iambitchx \
      --signer-workflow jpzk/iambitchx/.github/workflows/release.yml \
      --source-ref refs/tags/v0.1.0

  ▌ SBOM attestation (CycloneDX, x86_64 linux binary and tgz):
    gh attestation verify iambitchx-0.1.0-x86_64-unknown-linux-musl \
      --repo jpzk/iambitchx \
      --predicate-type https://cyclonedx.org/bom
