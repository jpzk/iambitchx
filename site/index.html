A BitchX-style Matrix client for the terminal. Channels, not rooms; IRC vocabulary, Matrix underneath, end-to-end encrypted.

what it does

IRC vocabulary

/join /part /names /who /whois /msg /query /me /topic /invite /kick /op /deop /mode /away /nick /set /window /encrypt /verify /trust /devices /recover

Matrix, properly

End-to-end encryption, SAS emoji verification, device keys, recovery. Login by OAuth device link or password; tokens refresh themselves before they expire.

Terminal native

A BitchX-style status window, split windows, IRC-style timestamps, status bar and prompt. No mouse required.

build & run

cargo build --release
./target/release/iambitchx            # default profile
./target/release/iambitchx -P <name>  # another profile

First start logs you in (OAuth device link or password). Type /help for the command list.
